FINDING HELP

How to find help in any workshop

  1. Look in the room first. Use its Help ▾ menu, Help section, or Documentation & source panel. That documentation was written for the benches on that page.
  2. Open the full documentation. The README link in Help carries the complete portable guide for the room, including start-up, offline notes, sources, and checks.
  3. Inspect the source. The GitHub link in Help opens the maintained source for that workshop — the same files the page is built from.
  4. Use the directory below. It lists every catalogued project with direct routes to the workshop, its documentation, its README, and its source.
  5. Still stuck? Check Troubleshooting on this page, then report the problem through GitHub Issues with the room name and what you expected to happen.

A note on README links

A README link opens the room's Markdown file. On GitHub it appears as a formatted page; in a downloaded folder or the desktop app, a browser may show the plain Markdown text or offer it as a file. The words are the documentation either way — headings begin with #, and links are written in brackets.

DESKTOP APP

Using the desktop app

The Help menu

  • Help → Documentation opens the app's bundled documentation page.
  • Help → Product Index opens the index of Steven Powell's products in your browser.
  • Help → About shows the app name and the version you are running — the first thing to check when a room looks out of date.

Users, cache, and stale pages

  • User profiles keep each person's room progress, preferences, and cache separate on a shared machine. The first user, Default, adopts the data the app already had.
  • File → Switch User returns to the profile picker; File → Add User creates another profile.
  • File → Clear Cache is the standing cure when a room serves its pre-update copy: it clears cached pages and service workers for the current user, then restarts the app. Saved progress and preferences are deliberately left untouched.

The desktop app is built from this collection, so the rooms and their Help documentation are the same on the web and in the app. Links that leave the workshop open in your default browser, leaving the app where you left it.

OFFLINE · PRIVACY · ACCESSIBILITY

Built to travel, plainly labelled

Offline and privacy

Most benches compute locally in your browser or in the desktop app, with no account and no tracking. A room's Help and README state its own exceptions plainly: live weather and place searches, map tiles and directions, radio streams and scanner lookups, satellite-orbit refreshes, external reading, and videos all need the internet because their data or media lives elsewhere.

When a feature sends something — a place name, coordinates, or a search — the room's documentation says what is sent, where, and why.

Accessibility

Accessibility is a standing requirement across the collection: readable navigation, full keyboard access, visible focus, labelled controls, sufficient contrast, no compulsory motion or autoplay, and respect for reduced-motion preferences. Each room's README and sources note feature-specific alternatives and limits.

If you meet a barrier, please report it as a correction through GitHub Issues. Barriers are first-class fixes, not finishing touches.

TROUBLESHOOTING

When something looks wrong

  • A page looks stale or a new room is missing. In the desktop app, use File → Clear Cache and let the app restart. On the web, hard-refresh the page (Ctrl+Shift+R on Windows, Cmd+Shift+R on macOS). Check Help → About in the app to confirm the version you are running.
  • A room says it needs the internet. That is the room being honest, not broken: live forecasts, place and map services, streams, orbit refreshes, and external shelves live on other people's servers. The room's Help section names exactly which parts need a connection and which keep working offline.
  • A README opened as plain text. That is the raw Markdown file doing its portable job — see the note under “How to find help.” For the formatted version, open the same README from the workshop's GitHub source link.
  • A link opened outside the app. By design: documentation sources, live services, and downloads' home sites open in your default browser so the workshop stays where you left it.
  • Satellite or weather data looks old. Rooms that use changing data label its age or retrieval time on the page. Reconnect and use the room's refresh or live-lookup control; offline copies are labelled as snapshots, never presented as current.
