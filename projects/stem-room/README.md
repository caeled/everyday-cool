# The STEM Room

An Everyday Cool landing room: the collection's six science workshops gathered behind one card on the main hub. The STEM Room holds no benches of its own — it is the shared front door for Everyday Physics, Everyday Chemistry, Everyday Electronics, Everyday Measure, Everyday Body, and The Radio Room, each of which keeps its own page, its own files, and its own web address, unchanged.

## What's inside

- **The six doors** — one card per workshop, in the order Physics, Chemistry, Electronics, Measure, Body, Radio Room, each carrying the same hook, description, and "start here" line the main hub used to show, and linking to the workshop's existing page.
- **How they connect** — a short section on the ways the six lean on each other: Measure's prefix ladder is spent by Electronics and Chemistry; Electronics builds the crystal radio the Radio Room listens through (the two rooms link both ways); Body is the machine the other five measure, power, and describe.
- **Help menu** — the header's **Help ▾** menu opens the documentation directly (the six doors, whether the rooms moved, the offline answer), plus a "Full documentation (README)" entry. This README ships inside the desktop app copy, so Help's full documentation works in the app too.

## Run it

Open `index.html` in a browser. The page is static — one HTML file, a stylesheet, and the banner — and works fully offline, including inside the desktop app. The six workshops behind the doors work as they always have; only the Radio Room's live streams and scanner feeds need the internet.

## Files

- `index.html` — the room itself
- `style.css` — the shared Everyday Cool room styling
- `stem-room-banner.jpg` — AI-generated banner art (see COLLECTION.md)
