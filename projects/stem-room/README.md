# The STEM Room

An Everyday Cool landing room: the collection's science workshops gathered behind one card on the main hub. The STEM Room holds no benches of its own — it is the shared front door for Everyday Physics, Everyday Chemistry, Everyday Electronics, Everyday Measure, Everyday Engineering, Everyday Body, and The Radio Room, each of which keeps its own page, its own files, and its own web address, unchanged. It opened with six doors on 19 November 2026; Everyday Engineering became the seventh the same evening.

## What's inside

- **The seven doors** — one card per workshop, in the order Physics, Chemistry, Electronics, Measure, Engineering, Body, Radio Room, each carrying the same hook, description, and "start here" line the main hub used to show, and linking to the workshop's existing page.
- **How they connect** — a short section on the ways the seven lean on each other: Measure's prefix ladder is spent by Electronics and Chemistry; Electronics builds the crystal radio the Radio Room listens through (the two rooms link both ways); Engineering spends the forces Physics names and walks its six machines into the Survival Guide's field skills; Body is the machine the other six measure, power, and describe.
- **Help menu** — the header's **Help ▾** menu opens the documentation directly (the six doors, whether the rooms moved, the offline answer), plus a "Full documentation (README)" entry. This README ships inside the desktop app copy, so Help's full documentation works in the app too.

## Run it

Open `index.html` in a browser. The page is static — one HTML file, a stylesheet, and the banner — and works fully offline, including inside the desktop app. The seven workshops behind the doors work as they always have; only the Radio Room's live streams and scanner feeds need the internet.
