First Program — a tiny BASIC you can watch think

This is a small computer that speaks one small language. Every word the machine knows is in the dictionary on the left — if a word is not there, the machine cannot be told that thing. Write a program in the middle, then run it slowly and watch: the line being read lights up, every variable sits in a named box on the right, and the output appears one statement at a time. There is no hidden magic anywhere on this page — and the back-door lesson shows the machine's own working.

    Missions — checked by the machine itself

    Each mission runs your program on this same machine, with the same seed, and compares what it prints, line by line.

    Honesty, up front: the checker reads output, not code. A program that just PRINTs the answers passes missions 1–3 — and then the machine did the learning, not you. Mission 4 is guarded a little better: it is checked twice, with different numbers, so a memorised answer fails the second check.

    What this leaves out

    Stated plainly: this is a tiny dialect of BASIC. There are no arrays, no DATA/READ, no files, no graphics, and IF … THEN can only jump to a line number — real BASICs let a whole statement ride after THEN. Programs are stopped after 100,000 statements: that step budget is a kindness real machines do not offer (a real machine would simply hang, forever, on 10 GOTO 10). Numbers are IEEE doubles, so PRINT 0.1 + 0.2 honestly prints 0.30000000000000004. And the mission checker reads output only, as the note above says. Everything else on this page is exactly what it claims to be.
