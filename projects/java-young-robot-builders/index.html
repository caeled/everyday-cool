FROM THE WIDER WORKSHOP

Games that teach — and show their work.

Twenty games elsewhere in Everyday Cool keep a back door open: a page that explains the physics inside the game and shows how the game was coded — real formulas, worked examples, and the tricks the builders used. Arranged gentlest first: new readers, start with Laser & Mirrors and Tune the String.

BACK DOOR 01 / EVERYDAY LIGHT

Laser & Mirrors

Bounce a laser around corners with mirrors — then read how one small tracer program both draws the beam and proves every puzzle can be solved.

Read the back door →BACK DOOR 02 / EVERYDAY SOUND

Tune the String

Tune a string by ear until the wobble between two notes dies away — then read how the game makes that wobble for real, by adding two sound waves together.

Read the back door →BACK DOOR 03 / EVERYDAY PHYSICS

Ballast

Float a submarine at exactly the right depth — then read how the game's test pilot had to win using only the gauges the player can see.

Read the back door →BACK DOOR 04 / EVERYDAY PHYSICS

Stage It

Send up a two-stage rocket — then read how one piece of math code powers the design screen, the flight, and the proof that each level can be beaten.

Read the back door →BACK DOOR 05 / EVERYDAY PHYSICS

Docking

Dock with a space station, where speeding up makes you fall behind — then read how a careful integrator and a script-flown rehearsal keep the orbits honest.

Read the back door →BACK DOOR 06 / EVERYDAY ENGINEERING

Shake Table

Build a tower that survives an earthquake — then read how the builders searched backwards from “it stands” to find the designs worth testing.

Read the back door →BACK DOOR 07 / A LIBRARY

Shelf It!

Shelve a book by its Dewey number, then guess a subject from a bare number — then read how one data table deals the questions, grades the answers, and prints the lesson's own catalog.

Read the back door →BACK DOOR 08 / EVERYDAY ELECTRONICS

Don't Cook the LED

Choose the resistor that lights an LED without cooking it — then read how one small formula, fenced off as pure code, is shared by the game and the test that proves every level can be won.

Read the back door →BACK DOOR 09 / EVERYDAY COMPUTING

Wire the Adder

Wire logic gates into a circuit that adds — then read how the circuit is stored as a readable list of gates and wires, small enough to check by hand, and graded against the whole truth table.

Read the back door →BACK DOOR 10 / NERD HEAVEN

Find the Fault

Diagnose a dead machine by choosing tests and reading their pattern — then read how a table of what each test says about each fault becomes both the game and the solver that proves every case can be cracked.

Read the back door →BACK DOOR 11 / MAP ROOM

Go Thataway

Walk by compass bearing and pace count while your stride quietly veers — then read how the game keeps two positions at once: the true one, and the one you believe, and why the fix is the whole skill.

Read the back door →BACK DOOR 12 / EVERYDAY CHEMISTRY

Balance It

Build molecules and balance equations — then read how one small program reads a formula like Ca(OH)₂ and counts its atoms, and how that same counter judges your answers.

Read the back door →BACK DOOR 13 / SECRET SQUARES

Pass It On

Send a message down a channel that corrupts it — then read how a single extra digit can catch a lie, and how a grid of guards can point at the exact spot that changed.

Read the back door →BACK DOOR 14 / PACKET PLAYGROUND

Route It

Walk a packet across a little network one hop at a time — then read how each router only knows the next turn, how the packet's notebook catches a loop, and what finally stops it.

Read the back door →BACK DOOR 15 / DECISIONS EVERYWHERE

The Boring Bet Wins

Pick between three bets whose prices are printed on the door — then read how a tiny edge, collected a thousand times, beats a jackpot that almost never comes, counted over a hundred long runs.

Read the back door →BACK DOOR 16 / SATELLITE WATCH

Catch the Pass

Call a satellite's pass before it flies — how high it will peak, and when — then read how the game builds a pass from two numbers and judges your call to the degree.

Read the back door →BACK DOOR 17 / EVERYDAY MEASURE

Anchors

Estimate a mouse, an elephant, the Moon — then read how the game scores you by the factor you missed by, and why being off by a little and being off by a lot are measured on a multiplying scale.

Read the back door →BACK DOOR 18 / NERD HEAVEN

Corrected by Halves

Ten games about cutting a problem in half until it confesses — then read the audit: which of its claims the code proves (a real CRC, an exact Hamming syndrome) and which it merely says.

Read the back door →BACK DOOR 19 / GAMES ROOM

Zenith Othello

A Reversi brain that starts knowing literally nothing — eleven zeros — and learns by playing, even against itself. Read how the audit proved the learning is real: the corners catch fire, and the wins follow.

Read the back door →BACK DOOR 20 / GAMES ROOM

Zenith Chess

A chess brain that starts with every piece worth exactly one — a pawn is a queen is a king — and has to discover the difference by playing. Read what 5,000 self-played games taught it, and what its classroom never teaches.
