Balance It — Build & Balance

Build the molecule: tap an element tile to add one atom; the − button takes one back. Balance the equation: the − and + steppers set each coefficient from 1 to 9 — whole numbers only, because an equation is a recipe ratio and there is no such thing as half a molecule in the count. The ledger under the equation keeps the atom tally live: a row turns green when that element matches on both sides.
