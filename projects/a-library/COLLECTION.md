Dewey Decimal and Shelf It! (21 November 2026): Steven Powell's own addition for this room. `a-library.html` gained a "The Dewey Decimal System" section — the ten main classes with one-line notes and a plain-language account of the system's vagaries (computers in the 000s, other religions squeezed into the 290s, literature by language, migrating numbers, biography's three homes, fiction's escape, local bending). `dewey-game.html` is **Shelf It!**, a two-mode guessing game (here is a book — which section; here is a number — what lives there) driven by one embedded table of the hundred divisions and a 40-book deck; 040 stays in the table as honestly Unassigned and is never dealt. `dewey-game-lesson.html` is its back door: how Dewey works, the full catalog of the hundred divisions generated from the game's own table so the two cannot drift, worked examples, the vagaries expanded, a "From the screen to the shelf" walk written at Steven's direction the same morning, and the simplifications named (DDC is a living, trademarked OCLC system; the deck is invented teaching examples). Secret Squares links across to the game from its UPC section — a call number is a code — and the lesson links back. The game also visits the Physics Game Table, the Arcade shelf, and both lesson shelves. Changed files: `a-library.html`, `dewey-game.html`, `dewey-game-lesson.html`, `README.md`, `COLLECTION.md`.

Subject search (21 November 2026): at Steven Powell's direction, `dewey-game.html` gained a subject search — type a subject ("chickens", "dreams", "soccer") and it returns the Dewey number: the precise section where one exists (636 inside division 630), the division, its main class, and a why line, from the game's own DIVISIONS table plus a hand-kept map of 100 everyday keywords. A nonsense word gets an honest empty with broader-word suggestions — never an invented number. The panel links the collection's Find It room (subject-searching is that room's trade; this is its library cousin), and Find It's Keep Going shelf links back. `dewey-game-lesson.html`'s How it's built and simplifications describe the search as what it is: a teaching index, not the full DDC schedules. The game's original proofs were re-run against the edited file and still pass. Changed files: `dewey-game.html`, `dewey-game-lesson.html`, `README.md`, `COLLECTION.md`.
