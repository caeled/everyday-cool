# A Library

By Steven Powell, Everyday Cool.

Open `a-library.html` in a browser or double-click `Launch.cmd`. No installation or framework required.

A reference shelf of 35 links across books, reference, science, history, Earth, sky, and making. The directory works offline; the linked collections need internet and retain their own access rules.
