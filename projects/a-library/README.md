# A Library

By Steven Powell, Everyday Cool.

Open `a-library.html` in a browser or double-click `Launch.cmd`. No installation or framework required.

A reference shelf of 43 links across books, reference, science, history, Earth and sky, and images and music. The directory works offline; the linked collections need internet and retain their own access rules.

The room also carries a Dewey Decimal card — the ten main classes and the system's vagaries in plain language — and **Shelf It!** (`dewey-game.html`), Steven Powell's own game for the room: here is a book, which section does it shelve in; here is a number, what lives there. Its lesson (`dewey-game-lesson.html`) prints the full catalog of the hundred divisions and walks from the screen to the shelf. The game page also carries a subject search: type a subject and it kicks out the Dewey number — the precise section where one exists, its division and class, and a why line — from the same table plus a hand-kept map of everyday keywords, with an honest empty when nothing shelves there. Secret Squares, the codes room, links across to it — a call number is a code like any other there.

The shelves have kept growing past that first 43. The newest (24 November 2026) is **AI & Machine Learning** — DeepMind and its research index first, at Steven's direction, then the primary sources behind Nerd Heaven's Attention and Backprop labs (Vaswani et al. 2017, BERT, Nielsen's textbook, Rumelhart/Hinton/Williams 1986, Kingma & Ba's Adam) — shelved with the wave of Computer Science & AI references that arrived with it (Raft, SEC 1, Shannon 1948, and more under Electronics & Computing) and the Mechanical/Robotics wave's sources under Engineering & Making. The library now holds 329 entries.
