# External resources

This package contains a directory of links, not copies of the linked books, papers, images, or archives. Each destination and each item retains its own access rules, licenses, and copyright status. Public-domain status can differ by country. Check rights before redistributing an external item. Some borrowing services require a free account or have limited availability.
