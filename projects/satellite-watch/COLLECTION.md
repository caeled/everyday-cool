# Collection origin

Original Everyday Cool workshop, added 16 November 2026 at Steven Powell's request for general satellite tracking in a new room, leaving Tonight's Sky's own ISS / Starlink / Dragon features as they are. Built by Grok Bot (AI assistant) and proposed by pull request for Steven's review; this folder is the maintained original, and there is no upstream copy.

Reused within the collection (copied unchanged, so this room's ZIP works on its own): `vendor/satellite.min.js` and `vendor/satellite-js-LICENSE.md`, `satpass.js` and `astro.js` from `projects/tonights-sky`; `LICENSE`, `LICENSE-CONTENT.md` and the base of `style.css` from `projects/find-it`. The Leaflet map, Find me fallback and ZIP-box patterns follow Find It.

At Steven's request the room links to Tonight's Sky and to the existing backyard radio telescope plan PDF in `projects/tonights-sky/downloads/` (the same file Space Camp links; it is not duplicated here). Tonight's Sky and Space Camp link back to this room.

Local changes: `index.html` gained the room's banner figure on 16 November 2026, when the AI-watercolor banner (`satellite-watch-banner.jpg`, a robot at a brass telescope under the satellites, Steven's art direction) was added at Steven's request; the banner file was added the same day. Provenance hashes for both were refreshed on 17 November 2026 while adding The Radio Room, after the collection check flagged the banner commit's unrecorded change. On 24 November 2026 `index.html` gained the curator's note under the hero (Steven's framing of a communications satellite as a remote robot telephone/data exchange, with Muse's embellishments added at his direction), and the provenance hash was refreshed the same day.

Documentation update (20 November 2026): at Steven Powell's direction, `index.html` gained the shared documentation action bar and curator profile line inside its existing Help section, linking the README, GitHub source, sources and limitations, workshop download, and collection documentation index. Changed files: `index.html`, `COLLECTION.md`. The addition is documentation and navigation only; no lesson content or workshop behaviour was changed.

Game (21 November 2026): at Steven Powell's direction, the room gained its first game — `catch-the-pass.html`, **Catch the Pass**: call a pass before it flies (peak elevation and time-to-peak, the peak not always at half time because the arc is asymmetric), then the umpire rules on the call sheet — inside the round's fair line, CALLED IT FAIR; wide of it, foul by the exact degrees. The stamp and the game's cross-link deliberately echo Steven Powell's own Called It Fair scoreboard shelf (https://caeled.github.io/called-it-fair-scoreboard/), a separate site of his; the shelf links back to the game, making the cross-link both directions. `catch-the-pass-lesson.html` is its back door (passes and twilight windows, peak elevation, angular error against a fist at arm's length, no TLE/SGP4 and no magnitude model named as simplifications), opened from inside the game by a Lesson pop-up. `index.html` gained a game card in the Help section's grid. The game also visits the Physics Game Table, the Arcade shelf, and both lesson shelves. Changed files: `catch-the-pass.html`, `catch-the-pass-lesson.html`, `index.html`, `README.md`, `COLLECTION.md`.

Cross-link (24 November 2026): `index.html` gained one line in "05 / KEEP GOING" pointing to the new Everyday Physics exhibit `../everyday-physics/rocketry-thrust.html` (Rocketry & Thrust — how the satellites got up there, and an orbit bench that throws a ball sideways from 400 km). Navigation only; no workshop behaviour changed. Changed files: `index.html`, `COLLECTION.md`.
