# Collection origin

Original Everyday Cool workshop, added 16 November 2026 at Steven Powell's request for general satellite tracking in a new room, leaving Tonight's Sky's own ISS / Starlink / Dragon features as they are. Built by Grok Bot (AI assistant) and proposed by pull request for Steven's review; this folder is the maintained original, and there is no upstream copy.

Reused within the collection (copied unchanged, so this room's ZIP works on its own): `vendor/satellite.min.js` and `vendor/satellite-js-LICENSE.md`, `satpass.js` and `astro.js` from `projects/tonights-sky`; `LICENSE`, `LICENSE-CONTENT.md` and the base of `style.css` from `projects/find-it`. The Leaflet map, Find me fallback and ZIP-box patterns follow Find It.

At Steven's request the room links to Tonight's Sky and to the existing backyard radio telescope plan PDF in `projects/tonights-sky/downloads/` (the same file Space Camp links; it is not duplicated here). Tonight's Sky and Space Camp link back to this room.

Local changes to imported files: none (no files were imported; all files originate in this collection).
