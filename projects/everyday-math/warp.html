What you are looking at

Warp is a tribute to Acidwarp, the classic DOS "psychedelic screen saver" of 1992–93 by Noah Spurrier and Mark Bilk. The trick, then and now: draw one picture of index numbers 0–255 from a little maths (rings, spirals, waves…), then rotate the palette every frame. The colours flow through the shapes and nothing is redrawn. Every so often: fade to black, new picture, new palette, fade in. The strip under the picture is the live palette — watch the marker ride it while the picture itself never changes. The See the index picture button shows you the one static picture, in grey: every colour you have seen was the palette moving, not the picture.

The pictures

Nine generators, each a formula over a coordinate grid measured in classic 320×200 units: RINGS (distance from a wandering centre), SPIRAL (radius plus whole turns of angle — whole turns only, so there is no seam), WAVES (a few sine waves at random angles, stretched across the palette), PLASMA (four sines: x, y, x+y, and radius), KALEIDO (the angle folded into one wedge and mirrored), INTERFERENCE (two or three centres, distances added, subtracted, or multiplied), TUNNEL (3000 / (radius + 8) — rushing inward forever), WARP (x dragged sideways by sines), and JULIA (a true Julia-set escape count for one of eight classic constants, nudged a little each time).

The palettes

Every palette has exactly 256 colours and loops seamlessly — the step from the last entry back to the first is as small as any other step, so rotating it never shows a join. COSINE builds each channel as a + b·cos(2π(ct + d)) with a whole-number frequency c — that whole number is what makes the loop exact. RAINBOW is the same cosine with the three channels a third of a turn apart. FIRE ramps black → red → yellow → white and back down (and half the time flips to "blue fire"). DUOTONE breathes between two random colours. BANDED quantises a cosine palette into hard stripes of 8, 16, or 32 — very 1993. Pressing P crossfades to a new palette over a second instead of cutting.

The keys

N or → next picture · P new palette · ↑/↓ palette speed · R reverse · Space pause · G see the index picture · F fullscreen · S save a picture · H help lines. Every control also has an on-screen button. Pictures hold for 20 seconds by default (10/20/40 selectable); the speed starts at 40 colours per second and the ↑/↓ keys multiply or divide it by 1.25, between 2 and 300.

The model, stated plainly

There is no model to bend — this is the genuine 1993 technique, not a simulation of it. The one modern substitution: the original drew its pictures with the machine's random generator, and this port uses a small seeded generator of its own, so a seed here repeats a picture here — but it is not Python's Mersenne Twister stream, and the same seed in the Python original deals a different picture. The property (same seed, same picture) is what was ported; the stream was not. The Python grid is also float32 where this port computes in float64 — the same formulas with one more byte of precision. The full write-up is on the lesson page.

The original

Warp was written by Steven Powell in Python (with numpy and pygame) in his Bordeom workshop. This page is a port: the nine generators and five palettes were carried over line for line, and the proof table below runs the original's own self-test checks against the shipped code. Its sibling Fractal imports these exact palettes — in the Python, fractal.py literally does from warp import PALETTES — and this page's palette code is the shared module both pages carry.
