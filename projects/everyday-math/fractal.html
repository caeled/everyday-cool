What you are looking at

Fractal is a Mandelbrot / Julia zoomer with Acidwarp-style colour cycling. In the 1980s a picture like this took minutes to hours and wanted a maths coprocessor; the classic 320×200 view here takes milliseconds. It starts in dive mode — a screen saver that falls into a spiral valley and keeps going: fade in, dive toward the target until each pixel spans 2×10⁻¹¹ of the plane, hold for four seconds, fade out, pick the next valley and a new palette. Click anywhere to take over and explore; press D to hand it back.

The maths in one breath

For each pixel c, iterate z → z² + c from z = 0. If |z| ever exceeds 256 the point has escaped, and its colour index is the smooth escape count nu = i + 1 − log₂(0.5 · ln |z|²) — the big bailout radius (65536 = 256²) is what makes the colour bands flow instead of stepping. Points that never escape are the set, drawn black. Two shortcuts keep it fast: points inside the main cardioid or the period-2 bulb are known to be in the set without iterating, and escaped pixels are dropped from the working set as they go, so the cost follows the detailed pixels, not the whole picture. The iteration budget grows with depth — 96 + 42 × depth, capped at 4000 — because deeper views need more iterations to resolve. Press J over any point to see the Julia set for that c instead (the iteration then starts from each pixel and adds the fixed c); press J again to come back.

The dive targets

The six valleys the dive visits — Seahorse valley, Triple spiral valley, Spiral, Deep spiral, Elephant valley, Misiurewicz spirals — were found by computation, not looked up: each was refined by zooming repeatedly toward the most detailed pixel, and the proof table below checks that every one is still full of detail at a zoom of 1e-9.

The keys

Left click zoom in on that point · right click zoom out · mouse wheel zoom at the cursor · arrows pan · PageUp/PageDown zoom · D dive · J Julia set of the point under the mouse (again to go back) · P new palette · [ ] palette speed · −/+ fewer/more iterations · Space pause colours · R reset · F fullscreen · S save a picture · H help lines. Every control also has an on-screen button.

The floor, stated plainly

Coordinates are double-precision floats, and that sets a hard floor: the zoom clamps at a pixel size of 1e-13 complex units. Below that, neighbouring pixels would land on the same representable numbers and the picture would go blocky — the floor is where float64 runs out of digits, and the page stops there rather than pretend. (Arbitrary-precision zoomers exist and go deeper; this one is honest about being a float64 machine.) Deep down, the page also draws at half size while diving if a full frame would take over 300 ms, and refines back to full size when the cost allows — the Python original's own trick. The palettes are shared with Warp: in the Python, fractal.py imports them — from warp import PALETTES — and both pages here carry the same palette module. The full write-up is on the lesson page.

The original

Fractal was written by Steven Powell in Python (with numpy and pygame) in his Bordeom workshop. This page is a port: compute(), the smooth colouring, the iteration budget and the six targets were carried over line for line, and the proof table below runs the original's own self-test checks against the shipped code. Two differences to know: the Python stores its smooth counts in float32 where the port uses float64 (one notch more precise — a colour index can differ by one at a band edge, nothing else moves), and the Python's screenshot key saves beside the script where this page downloads through your browser.
