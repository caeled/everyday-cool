The back door: how Echo Shift works

A shift is a list of commands. At each beat, the game applies the same movement rule to every robot, then checks whether a switch is occupied and whether the crate reached its goal. Replaying the same list from the same starting state produces the same result.

A closed door blocks movement. A robot can push the crate into a clear tile; the crate cannot be pulled. Each station has a machine-checked solution within its shift and echo limits. The solver enumerates programs, simulates them under the shipped rules, and accepts only a plan that delivers the crate.

This is a small model of parallel work. A useful plan lets one worker keep the switch occupied while another moves the cargo. When a plan fails, inspect the beat when the door closed or the workers got in each other's way. The echo is a recording, not a thinking opponent.
