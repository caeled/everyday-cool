      THE IDEA BEHIND THE FIX

      Parts cooperate.

      These tickets assume one fault from a small known list and reliable test fixtures. Real devices can have multiple faults, uncertain readings, and causes you have not considered. A result that fits is evidence—not a guarantee.

      Try it away from the screen: draw the working steps of a familiar object. Where could you observe an input and an output without taking it apart?

      Controls and offline use

      Use a mouse, touch, or Tab and Enter/Space. Every control has a text label. There is no timer and no required sound or animation. Open this folder’s HTML files directly in a browser; keep the CSS and JavaScript alongside them. Everything except external reading and searches works offline. Progress and notes last for this tab only; reloading starts fresh.

      How repairs are checked

      Choose a cause to see its predictions. Tests reveal recorded observations and show which explanations still fit. A repair is accepted only when tests distinguish a single cause and you have selected it. Apply that change, then repeat the functional test to finish. Next fault cycles through three deterministic faults per object.
