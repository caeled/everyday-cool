Local rules, global results

Each tile is a node in a graph. An edge exists between neighbors only when their facing ports are both open. The source can reach a whole component of this graph. That component may be large and still fail to contain the beacon.

The four-bit model

North, east, south, and west use values 1, 2, 4, and 8. An elbow pointing north and east is 3. A clockwise turn makes east and south: 6. Further turns give 12 and 9, then return to 3.

rotate(mask) = ((mask << 1) & 15) | (mask >> 3)
3 → 6 → 12 → 9 → 3

A straight segment has two distinct orientations: north/south is 5, east/west is 10. Four rotations always restore the starting orientation.

A worked connection

Tile 1 is the top-left source. In the first mission it has an east port. Tile 2 needs a west port for the pair to connect. Tile 5 is at the right edge: its east port cannot wrap to tile 6 on the next row. The neighbor function rejects that false connection.

Finding Bolt’s route

Breadth-first search starts with the source in a queue. It visits connected neighbors, remembers their parents, and adds unvisited neighbors to the queue. When it finds the beacon, tracing parents backward produces a shortest route in number of edges.

The first intended route uses tiles 1, 2, 3, 4, 5, 10, 15, 20, and 25: nine tiles and eight edges. The game reports tiles, not meters or seconds. At most 25 vertices and four neighbors per vertex make searching after every turn inexpensive.

Why it is coded this way

Pure functions in engine.js handle rotation, neighbors, reachability, and routes. app.js renders ordinary buttons containing SVG paths, so touch and keyboard use the same rules. Completed routes appear immediately rather than requiring animation.

Each mission starts from a known valid route, then rotates tiles deterministically. Hints restore one intended-path tile. Any valid route is accepted. Undo stores board snapshots and counters.

Try changing one thing

Sketch a 5 × 5 route, turn two elbows, and predict which cells stay connected. For a coding experiment, change a mission path while keeping consecutive cells adjacent, then run node test.cjs to catch impossible steps.

Where the model stops

These are abstract service signals. There is no voltage, resistance, return conductor, load, or real door controller. Actual electrical circuits require more than graph connectivity.
