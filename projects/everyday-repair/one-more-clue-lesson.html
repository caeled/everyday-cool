The useful clue separates explanations.

Prediction before observation

A hypothesis is an explanation that leads to predictions. Choose a working theory, read its prediction, then compare it with the observation. A mismatch is a reason to reconsider the theory—or check the observation and assumptions.

A worked example: the clock

Four explanations are offered: a slow display, a brief stop, a reset, or a fast reference. Two agreeing references rule out the fast-reference explanation in the game. Three candidates remain. A growing gap an hour later fits a slow display, while a simple stop or reset predicts a fixed gap. One remains. Frame color leaves all four candidates, since all predict blue.

The actual rule

remaining = explanations matching EVERY observed clue
close case = exactly one remains AND you chose it

This is logical elimination, not a confidence calculation. One survivor in the game is not 100% confidence about a real event.

How much did a clue distinguish?

Under an equal-weight assumption, reducing four candidates to two is log₂(4/2) = 1 bit; four to one is log₂(4/1) = 2 bits. Four staying four is 0 bits. This illustrates candidate-set reduction. The game does not assign probabilities or use bits as a score.

Changing your mind is allowed

Guessing early cannot close a case. Your theory must be uniquely supported. Revisions are counted without penalty, and there is no timer. Comparing predictions is more useful than defending a first guess.

How it is coded

Each case has four explanations and a table predicting each clue under each explanation. A fixed case index determines the observation. A pure filtering function also powers the repair bench. Progress and notes are separate for each case and kept in tab memory only.

Explicit tables make the logic auditable. Tests enumerate every evidence subset and check that the modeled true explanation is never eliminated. Native buttons, selects, and textareas provide keyboard access and visible focus.

Real evidence is messier

The game assumes a complete list of mutually exclusive causes, reliable observations, and one cause per case. Real inquiries can involve several causes, unreliable instruments, and missing alternatives. Evidence may change confidence instead of eliminating an explanation. A good investigator can say “we do not know yet.”

Try it with a group

Before opening a clue, predict its results under each theory. Choose one whose outcomes differ. After revealing it, ask which explanations still fit and which assumption you would check next.
