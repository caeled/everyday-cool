# Nerd Heaven — The Tech Support Workshop

A practical introduction to IT support by Steven Powell: the course I wish I had when I was learning by fixing things, mostly on my own.

**27 lessons · 8 subject areas · 4 offline practice benches · No course account or subscription required**

[Open the course](https://caeled.neocities.org/learn/)

## Easy download — no Git needed

[Download the ready-to-use course ZIP](https://github.com/caeled/nerd-heaven-tech-support/releases/latest/download/Nerd-Heaven-Course.zip)

Right-click the ZIP, choose **Extract All**, then open **START-HERE.html** in the extracted Nerd-Heaven folder. You can copy the whole folder to a USB stick. The lessons and practice benches work immediately without internet.

On Windows, **Download-Media.bat** adds optional publisher recordings beside the course. Choose four videos (~3.3 GB), the full collection (~3.7 GB), the two-hour starting route (~195 MB), or reading material only. It needs internet during the download; saved recordings then play offline. No administrator account or extra installation is needed on current Windows 10/11.

## Start learning

Download this repository as a ZIP, extract it, and open `index.html` in a current browser. Keep `app.js`, `course.js` and `style.css` beside the index. You can also clone the repository.

Lessons, explained checkpoints, notes and simulated exercises work without internet. External documentation, recordings and real cloud-service exercises need a connection and, where relevant, an appropriate account. Offline alternatives are included.

## The course

- Troubleshooting, useful questions and clear support tickets.
- Windows, hardware, files, performance and printers.
- Networking: IP addressing, DNS, DHCP, Wi-Fi and evidence gathering.
- Ethernet cabling, T568A/T568B and wire-map faults.
- Microsoft 365 / Office 365 and Google Workspace support concepts.
- Account security, phishing, recovery and responsible support tools.
- A practical portfolio and capstone you can demonstrate.

The starting check helps you choose a route. The network simulator, cable bench, sharing bench and ticket bench let you practice without touching a production system. A printable workbook and mentor guide are included.

## Carry your progress

Browser progress does not automatically travel with a USB stick. Use **Save progress to USB**, retain the downloaded JSON file, then use **Load progress** on another computer. Use fictional data for practice.

## The Back Doors — game lessons for builders

Twenty games keep a back door open: a lesson page that explains the physics — or the method — the game runs on and shows how it was coded, with the proof that its levels can actually be beaten. The workshop home shelves all twenty as builder reading, because every game's "How it's built" section points onward to this bench. This bench's own game leads the list:

- [Find the Fault — the lesson](find-the-fault-lesson.html) — this workshop's own game: four dead machines, six suspects each, diagnosed by the pattern of test results. An outcome matrix is the whole world; the greedy solver that proves every case crackable reads the same table the player reasons over, and par is the solver's own score.
- [Docking — the lesson](../everyday-physics/docking-lesson.html) — a pure-function orbital core stepped with RK4, flown by a script to prove every level dockable.
- [Stage It — the lesson](../everyday-physics/stage-it-lesson.html) — one rocket-equation core serving the design screen, the flight, and the test.
- [Ballast — the lesson](../everyday-physics/ballast-lesson.html) — a proof pilot that flies on the same instruments the player gets.
- [Laser & Mirrors — the lesson](../everyday-light/laser-mirrors-lesson.html) — a beam tracer that doubles as the prover of its own levels.
- [Tune the String — the lesson](../everyday-sound/tune-the-string-lesson.html) — real Web Audio synthesis; the beating is summed tones, not a sound effect.
- [Shake Table — the lesson](../everyday-engineering/shake-table-lesson.html) — a lumped-mass model searched backwards by inverse iteration.
- [Don't Cook the LED — the lesson](../everyday-electronics/dont-cook-the-led-lesson.html) — one Ohm's-law formula, fenced as a pure core the page and the proof share.
- [Wire the Adder — the lesson](../everyday-computing/wire-the-adder-lesson.html) — circuits stored as a readable netlist; the truth table is the judge.
- [Shelf It! — the lesson](../a-library/dewey-game-lesson.html) — one Dewey table read both ways; the answer key and the catalog can never drift apart.
- [Go Thataway — the lesson](../map-room/go-thataway-lesson.html) — a core that keeps only the truth; the proof navigator plays with the player's information, never the truth.
- [Balance It — the lesson](../everyday-chemistry/balance-it-lesson.html) — one formula parser serves both modes and the judge; "balanced" and "finished" are separate checks.
- [Pass It On — the lesson](../secret-squares/pass-it-on-lesson.html) — a seeded channel with declared corruption recipes; the catches are exhaustive counts, not hopes.
- [Route It — the lesson](../packet-playground/route-it-lesson.html) — the table is data and the walk is one pure function; the loop dies at exactly its TTL.
- [The Boring Bet Wins — the lesson](../decisions-everywhere/the-boring-bet-wins-lesson.html) — EV as exact fractions; the long run counted, not asserted (100 runs, 100 flashy ruins).
- [Catch the Pass — the lesson](../satellite-watch/catch-the-pass-lesson.html) — an analytic arc and a pure scoring function; the umpire is arithmetic.
- [Anchors — the lesson](../everyday-measure/anchors-lesson.html) — one anchor table drives the shelf, the feedback, and the proof's estimator; the three can never drift apart.
- [Corrected by Halves — the lesson](corrected-by-halves-lesson.html) — the collection's audit of Gemini Neon's ten-op halving suite: what's genuine, what's named loosely, checked against the code.
- [Zenith Othello — the lesson](../games-room/zenith-othello-lesson.html) — a learning claim that survives its audit: eleven zeroed weights, self-play, and a benchmark that moves 21% → 90%.
- [Zenith Chess — the lesson](../games-room/zenith-chess-lesson.html) — perft-verified chess rules and piece values learned from all-ones: the ordering is textbook, the magnitudes are its own.

## Two new benches (23 November 2026)

Built by Muse at Steven Powell's direction, to the Electronics Wave standard — one fenced pure core per bench driving the page and its `runProofs()` harness both, the lesson printing the measured numbers:

- [Transistor Up — Build a Computer](build-a-computer.html) · [the lesson](build-a-computer-lesson.html) — the whole stack on one bench: a transistor as a switch, NAND out of transistor states, AND/OR/XOR composed from NANDs, a full adder and a 4-bit ripple adder (proven over 65,536 pairs, zero mismatches), an SR latch and register, a tiny accumulator CPU whose ADD is the bench's own adder (demo program sums 1+2+3+4+5 to exactly 15, mod-16 named), and a GPU wing whose 16-lane output is element-identical to its serial reference. Twelve proof rows, all passing.
- [The Feedback Bench](feedback-bench.html) · [the lesson](feedback-bench-lesson.html) — PID control of a hovering rocket: P-only steady-state error measured 2.45253 against theory g/Kp = 2.4525; overshoot 36.67% against the damping prediction 37.23%; integral action drives the error to ~10⁻¹⁴; derivative action cuts overshoot from 90.03% to 36.67%; and the sampled loop's instability boundary found by simulation (Kp ≈ 1525) agrees with the discrete-pole computation (1552) inside 2%. The lesson names the philosophy plainly: corrected by halves, as an instrument.

Both benches are bannered on the workshop home above the Back Doors shelf, their lessons are shelved there (the shelf now holds seventy-five), and The Radio Room's Antenna Bench lesson joins them on the same shelf. The service worker cache advances to `nerd-heaven-v19`.

## Web Page Workshop (23 November 2026)

Built by Muse at Steven Powell's direction, for a young beginner who asked to be shown how to make a website:

- [Web Page Workshop](web-page-workshop.html) · [the lesson](web-page-workshop-lesson.html) — a kid-friendly WYSIWYG editor: a contentEditable canvas pre-filled with a starter page, a chunky labelled toolbar (bold, italic, underline, headings, size, colour swatches, lists, alignment, undo/redo, clear formatting) driven by `document.execCommand` (deprecated but universal, and named as such), picture insertion that embeds images as data URLs so the exported page is one self-contained file, a link maker (http/https only), a two-way View Source (pretty-printed HTML out; sanitized parse back in — scripts and event handlers stripped, so pasted code can change a page's looks but never run), localStorage autosave, and one serializer behind both Export (a standalone .html download) and Preview (the identical document opened as its own page in the default browser). Its nine interactions were driven headlessly at build time (jsdom, real button clicks; a minimal stand-in only for the execCommand primitives jsdom lacks) — 13 checks, 13 passed — and the same suite re-runs live on the bench. The bench is bannered on the workshop home beside Transistor Up, its lesson is shelved there (the shelf now holds one hundred eighteen), and A Library gained a Write the Web shelf of page-making references. The service worker cache advances to `nerd-heaven-v29`.

The **Computer Science & AI wave** (24 November 2026) is this bench's newest corridor: eight guest exhibits built by Google Antigravity (Gemini) at Steven's direction, integrated byte-for-byte — Attention (transformer self-attention), Perceptron (backpropagation), Cipher (ECC/DH/RSA/SHA-256), Pipeline (5-stage RISC CPU), Consensus (Raft), RayTrace (software ray tracer), Entropy (Huffman/LZW/DCT) and AlgoArena (sorting race + red-black tree) — each with a Muse audit lesson shelved here (the shelf now holds one hundred thirty-four) and a featured section at the top of the workshop home. The audits drove the shipped code against independent recomputation: two exhibits are PASS-grade clean, and the defects found — a violable Election Safety in Consensus, permanent NaN pixels in RayTrace — are documented in their lessons, deliberately unfixed. The service worker cache advances to `nerd-heaven-v31`.
