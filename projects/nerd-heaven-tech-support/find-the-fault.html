Hypothesis before hands.

Every case opens the way real calls open: with a story, told by the person it happened to — which means some of it is weather, not fact. Under the story there is one true fault, hiding among its lookalikes. Run tests from the bench — each one costs points — and write every result in the lab notebook. The suspects still standing narrow as the pattern grows. Commit when the pattern names one suspect, not when a single result waves at you: no single test in these cases can identify the fault. That is not a warning. It is the design.

The bench keeps score against par — the number of tests a scripted diagnostician, playing the same information you get, needs in the worst case. Solve at or under par and you are working like the script. Run every test on the menu and you are shotgunning, and the notebook will say so.
