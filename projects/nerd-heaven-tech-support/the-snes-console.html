The SNES Console — how to play

This page is a working Super Nintendo, emulated in your browser. The emulation core is Snes9x — a mature, high-compatibility SNES emulator, freeware for personal use — running inside the EmulatorJS frontend (GPL-3.0). Both are embedded unmodified; their licenses ride with this page (see the lesson for the receipts and the exact license texts). What the page deliberately does not contain is a single game. The console ships empty, the way the real one did: you bring the cartridges.

Insert a cartridge

  • Click Insert cartridge… and pick a .sfc or .smc file (a .zip holding one works too), or drag the file onto the console. The game starts as soon as it loads.
  • Point the picker anywhere your files live — a folder on this machine, or a mapped network drive. A mounted share is just a folder; the console reads the file right there.
  • The file is read on your machine only. Nothing is uploaded, nothing is sent anywhere, nothing is stored in the browser, and once this page has loaded it works fully offline — the emulator itself is served from this site, never from a CDN. Your library stays yours.
  • To play a different cartridge, reload the page and insert the next one — a fresh power-on, like the real deck.
  • The console's own toolbar (bottom of the screen once a game is running) has pause, reset, save/load state files, screenshots, and settings — that's EmulatorJS's furniture, and it all works.

Read that table carefully — it is not a misprint. The audit measured this build's pad at the cartridge, button by button, and the core hands the buttons over cross-wired under their labels: the face diamond (Z/X/A/S) lands correctly as A/B/X/Y, but Start lives on the E key, L on V, R on Enter — and the arrow keys do not reach the cartridge as a D-pad at all, nor does Select, through the keyboard path. The buttons that do arrive can be remapped in the console's controller settings. A USB or Bluetooth gamepad travels the same input path; whether its D-pad reaches the cartridge on this build is untested. The lesson carries the full measured map and what it means for which games play well here.

The challenge baton — hand a moment to the next player

  • Freeze any moment — a brutal jump, a boss at one hit point — with Export State Code below the console. The whole machine (CPU, picture and sound chips, cartridge state) packs into one block of text.
  • Hand the code to the next player however you like — a note, a message, a file. They insert the same cartridge, paste the code into Import, and the machine resumes at that exact moment. “Your turn to survive this.”
  • Honest size note: an SNES state is a lot of text — the lesson measures a real one, character by character. It travels by clipboard and message rather than riding the Baton Box: the Box serves single-file games, and this console is a small machine room of files. The lesson explains.

The fine print

  • Snes9x is one of the most compatible SNES emulators ever built, but no emulation is the hardware itself: a handful of games that lean on exact timing or exotic cartridge chips may behave differently. The lesson names the limits plainly.
  • No games are included, linked, or downloaded by this page — by design, and permanently. Homebrew you wrote, backups you made, test ROMs: those are yours to insert.
