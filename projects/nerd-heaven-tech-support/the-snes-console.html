The SNES Console — how to play

This page is a working Super Nintendo, emulated in your browser. The emulation core is Snes9x — a mature, high-compatibility SNES emulator, freeware for personal use — in its libretro build, launched by Nostalgist.js (MIT). Every piece is embedded unmodified; the licenses ride with this page (see the lesson for the receipts and the exact license texts). What the page deliberately does not contain is a single game. The console ships empty, the way the real one did: you bring the cartridges.

This console changed engines on 26 November 2026 — it ran on the EmulatorJS frontend before, and the lesson tells that story too, with the receipts for both.

Insert a cartridge

  • Click Insert cartridge… and pick a .sfc or .smc file (a .zip holding one works too), or drag the file onto the console. The game starts as soon as it loads.
  • Point the picker anywhere your files live — a folder on this machine, or a mapped network drive. A mounted share is just a folder; the console reads the file right there.
  • The file is read on your machine only. Nothing is uploaded, nothing is sent anywhere, nothing is stored in the browser, and once this page has loaded it works fully offline — the emulator itself is served from this site, never from a CDN. Your library stays yours.
  • To play a different cartridge, reload the page and insert the next one — a fresh power-on, like the real deck.
  • Once a game is running, the console's own buttons under the screen give you Pause and Reset, and the challenge baton below the console freezes and restores whole moments as text codes.

These bindings are set by this page, explicitly, in the core's own configuration — they are the same keys this page has always printed — and every row was re-measured at the cartridge with a pad-decoder cartridge and real key presses, against the hardware's own pad layout, most recently on the night of the engine swap (26 November 2026). They need saying plainly because an earlier printing of this table — this page's first version — had them crossed: it taught that Start hid on another key and that the arrow keys were dead. They aren't, and they never were; the test cartridge behind that printing named the joypad's two bytes in swapped order, so a correctly wired pad photographed as a rotated one. The lesson carries the full correction, in the open.

If the keys stop answering, click the game picture. Clicking elsewhere on this page — a button, this Help — can park the keyboard until you click back in. That is the likeliest cause of a "dead" console, and the note under the screen says so where you'll see it. The Export and Import buttons below the console hand the keyboard back on their own when you use them.

A USB or Bluetooth gamepad is read by the core directly, alongside the keyboard — the keyboard path is the one re-measured end to end for the correction and the swap.

The challenge baton — hand a moment to the next player

  • Freeze any moment — a brutal jump, a boss at one hit point — with Export State Code below the console. The whole machine (CPU, picture and sound chips, cartridge state) packs into one block of text.
  • Hand the code to the next player however you like — a note, a message, a file. They insert the same cartridge, paste the code into Import, and the machine resumes at that exact moment. “Your turn to survive this.”
  • Honest size note: an SNES state is a lot of text — the lesson measures a real one, character by character. It travels by clipboard and message rather than riding the Baton Box: the Box serves single-file games, and this console is a small machine room of files. The lesson explains.

The fine print

  • Snes9x is one of the most compatible SNES emulators ever built, but no emulation is the hardware itself: a handful of games that lean on exact timing or exotic cartridge chips may behave differently. The lesson names the limits plainly.
  • No games are included, linked, or downloaded by this page — by design, and permanently. Homebrew you wrote, backups you made, test ROMs: those are yours to insert.
  • The public shelf below the console is the one place this page points at games at all: it links out to the Internet Archive's own pages, where the cartridges stay on the Archive's shelves and play in the Archive's own player. Looking up a shelf link is the only time this page talks to the network, and it talks to the Archive only.
  • “SNES”, “Super Nintendo” and “Super Nintendo Entertainment System” are trademarks of Nintendo. This is a fan-made console page for playing your own cartridges, in descriptive use only.

On a touch screen: this build of the console has no on-screen gamepad — its controls are the keyboard (or a paired gamepad). On a tablet, pair a keyboard or a controller, or play on a desktop.

🏃 The challenge baton

Playing something brutal? Freeze the exact moment — mid-jump, mid-boss — and hand it to the next player. They insert the same cartridge, import your code, and the machine picks up exactly where you left it. A state code is big (the lesson measures one), but it is one block of text: copy it, send it, keep it in a note.

📚 Or borrow from the public shelf

The cartridges on this shelf live at the Internet Archive — a public library of software — and are served by the Archive, from the Archive. We host no games here; this page only opens the door. Your own library never leaves your machine, and nothing you borrow is kept here either.

Why a door, and not the slot? The Archive's file shelves don't currently let other pages take books down — their servers send no permission header, and browsers enforce that absolutely — so a shelf cartridge can't be loaded into this console directly today. Press a title and it opens on the Archive's own page, where the Archive's own player runs it in their house. The day the Archive opens that header, these same buttons will load the game right here.
