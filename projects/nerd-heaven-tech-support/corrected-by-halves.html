📘 Arcade Field Guide — Corrected by Halves

You don't read the whole station book from page 1—you split the problem in half, ask "which way?", and eliminate 50% of the search space every move. Every clean halving earns 1.00 bit of Shannon information (and 2D quadtree halving earns 2.00 bits!).

⚡ 1. Line Fault (1D Binary Search)

Tap the midpoint of the active trunk: CLEAN → cuts left, DEAD ← cuts right. Isolates 1 faulty relay out of 1,024 in max 10 probes.

🌳 2. Checksum Tree (CRC-8 Merkle)

Query half-range CRC-8 checksums to skip healthy subtrees, pinpoint the corrupt byte(s), and flip the bad bit via XOR delta.

📡 3. TCP Halver (AIMD Control)

Use ×2 Slow Start and +2/+8 to probe bandwidth, hit ÷2 HALVE on packet loss, and bisect into peak utilization.

⊞ 4. Parity Matrix (Hamming ECC)

Each parity mask (P1..P16) slices memory in half in space. Add the failing masks (ODD=1) to spell the flipped bit's exact binary address.

〰 5. Zero Crossing (Bolzano Bisection)

Sample black-box f(x) to zoom 50,000× into the root where f(x)=0—even on steep deceptive cliffs that fool giant-jump extrapolators.

🌿 6. Git Bisect (Commit Hunter)

Bisect up to 256 commits to find the exact regression commit that broke CI—even working around unbuildable SKIP commits.

🎯 7. Quadtree Radar (2D Halving)

Drop a crosshair at the center of the active map to halve X and Y at once—eliminating 75% of the area (2.00 bits) per ping! 65,536 tiles in 8 drops.

📶 8. Backoff Arena (CSMA / ALOHA)

Adapt contention window CW by powers of 2: ×2 cuts collision density in half during traffic bursts; ÷2 cuts idle waste when traffic drops.

🌐 9. Subnet Slicer (CIDR VLSM)

Slice a /24 network into halves (/25, /26, /27, /28, /29, /30) to fit each department's usable host count (2^h − 2) with zero waste.

🏆 10. Arcade Shift (Timed Boss Rush)

90-second continuous gauntlet mixing fast Fault, Quadtree, Hamming, Subnet, and Git challenges with combo multipliers and a local leaderboard!
