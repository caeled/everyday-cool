The DOS Console — how it works

This page is a working DOS PC, emulated in your browser. The engine is DOSBox Pure — a fork of DOSBox built for libretro, GPL version 2 or later — running inside the EmulatorJS frontend (GPL-3.0). Both are embedded unmodified; their licenses ride with this page (see the lesson for the receipts). What the page deliberately does not contain is a single game or a single byte of DOS software. The console ships empty, the way the real one did: you bring the software.

Door one — Mount your C:

  • This is the door for a whole DOS archive kept the way DOS people keep one: one folder that is a C: drive. Zip that folder — right-click it, Send to → Compressed (zipped) folder — and pick the zip here.
  • The console mounts the zip as drive C: and boots to a real DOS prompt, C:\>. No auto-run, nothing launched for you. DIR, CD, and typing a program's name work the way they did in 1990, because it is DOS in there.
  • How it works, honestly: DOSBox Pure loads a small boot file named CONSOLE.CONF. This page writes that file for you — in your browser, around your own files — and rebuilds the zip with it added. Nothing is uploaded. The rebuilt zip never leaves your machine; the emulator reads it right there.
  • Your zip can be as big as your archive. The console's zip tools are small, though: plain .zip only — no ZIP64, no password-protected entries. The status line will tell you in plain words if a zip can't ride.

Door two — one game, straight in

  • Pick a game zip and the console looks inside it for programs (.EXE, .COM, .BAT) and suggests the likely one in the Run command field. Confirm it, or type your own — the command runs exactly as typed, from C:\. If the suggestion points into a folder, the console steps into that folder first, the way you would.
  • If a game can't find its own files when run this way, it wants to be run from inside its folder — that's what door one is for: mount the drive, CD in, and run it at the prompt.

Door three — the public shelf (the Internet Archive)

  • The button opens The Oregon Trail (1990) — and the field under it opens any other item — in the Internet Archive's own player, in a new tab. The shelf is theirs, and for now the books are read in their house: the Archive's file servers don't currently give web pages permission to fetch the software itself, so no page — this one included — can honestly load it from there directly. The day the Archive opens those headers, this same door becomes a load-here door with no redesign. The lesson carries the evidence.
  • What the console can do with the Archive today: look the item up (their catalogue answers pages like this one freely), confirm it's really there, and take you straight to it.

The one hard requirement — a cross-origin isolated page

  • DOSBox Pure ships only in a threaded build, and threaded builds need SharedArrayBuffer, which browsers hand out only on cross-origin isolated pages. That means the server offering this page must send two headers: Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp.
  • Where that is true — the Baton Box on your own network, which sends those headers on its game routes, or any local server that does — this console starts and runs. Where it isn't — a plain static host that can't set headers, or this page saved as a lone file — the machine cannot switch on, and the console will tell you so in plain words instead of failing silently. Your files were never the problem; it's the room the page is standing in.
  • Starting the Baton Box from the shell: in the Baton Box folder, run python baton_box.py (on Windows, double-clicking start-baton-box.bat does the same) — it serves on port 8917 — then open this console through the box at http://localhost:8917/games/the-dos-console/the-dos-console.html.
  • Once it has started, everything is local: the emulator is served from this site, your zip is read on your machine, and the DOS machine makes no network requests at all.

Window size, fullscreen, pop out

  • Standard / Large / Extra large resize the window the DOS screen lives in; the emulator follows the box. Fullscreen gives the machine the whole display. Pop out lifts the running machine into a full-window view of its own — the same session, still running, nothing restarted — and Pop back in (or the Esc key) sets it back into the page.

Keyboard

  • DOS reads your real keyboard. Click the DOS screen once so it has focus, then type — letters, numbers, Enter, Backspace, the arrow keys, the F-keys and Esc go to DOS the way they did on the real machine. There's no gamepad translation layer to learn; a DOS machine is a keyboard machine.
  • The console's own toolbar (bottom of the screen once a game is running) is EmulatorJS's furniture: pause, restart, save/load state files, screenshots, settings — it all works, and it's upstream's, unmodified.

The fine print

  • No DOS software is included, hosted, or downloaded by this page's local doors — by design, and permanently. Your archive is read from your machine only.
  • Changes you make at the DOS prompt (a saved game, a high-score file) live in the machine's memory for the session. This page does not write back into your zip — download a fresh copy of your drive from your own folder when you want one; the zip on your disk is never touched.
  • “DOSBox” and “DOSBox Pure” are the names of their projects; “The Oregon Trail” belongs to its publisher. All are used descriptively — this is a fan-made console page for running your own software.

On a touch screen: the emulator draws its own on-screen gamepad — if it is not showing, tap the controller button at the edge of the player.

🏃 The challenge baton

Freeze the machine mid-game and hand the moment to the next player as a State Code — one block of text. They mount the same drive, paste the code into Import, and the machine resumes where you left it. A DOS machine is a lot of machine, so the code is big; the lesson measures a real one and says plainly how well this door works. The code can also ride the Baton Box — this console is one of its passengers, and the box is this console's playable home besides.
