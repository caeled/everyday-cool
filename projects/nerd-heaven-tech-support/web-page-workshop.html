What you are looking at

A workbench for making a real web page. The white sheet in the middle is a page being born: click in it and type, use the big buttons to dress the words up, and when you are happy, Export saves it as a real .html file — the same kind of file every website in the world is made of. Nothing here uploads anywhere. Everything happens on this machine, in this browser.

First steps

  • Click anywhere on the white page and type. The starter words are yours to change or wipe.
  • Select some words with the mouse, then press Bold, a colour swatch, or Big Heading and watch what happens to them.
  • Press </> View Source. That is the code your page is made of. Then come back and keep building.

The buttons

  • Write: Bold, Italic, Underline dress up the selected words. Big Heading / Smaller Heading / Normal turn a whole line into a heading or back. Bigger / Smaller change the size of selected words, the colour swatches change their colour, and Clear Formatting undresses words back to plain.
  • Arrange: Bullets and Numbers start a list. Left and Center move a line. Undo and Redo walk your changes backwards and forwards.
  • Add: Insert Picture puts a photo from this device into your page. Make a Link turns selected words into a link; Remove Link undoes one.

Insert Picture — why the picture lives inside the file

When you pick a picture, the workshop reads the picture's data and writes it into the page itself (a trick called a data URL). That is why your exported file can travel anywhere — emailed, put on a USB stick, opened on another computer — and the picture is still there. A normal web page points at a picture file somewhere else, and if that somewhere moves, the picture breaks. Yours can't. The trade: the file gets bigger by about the size of the picture.

Make a Link

Select the words first, then press Make a Link and type the address they should point at, like https://www.wikipedia.org. If you leave off the beginning, the workshop adds https:// for you. Only web addresses (http and https) are allowed.

</> View Source — the heart of this bench

View Source shows your page's actual HTML — the code it is made of — tidied up so a person can read it. And the door swings both ways: change the code in the source view, press Done — show my page, and the page re-renders from your edited code. Try changing a word in the code and see it change on the page. One safety rule: when code comes back from the source view, the workshop washes it first — scripts and sneaky attributes are stripped out, so pasted code can change how your page looks but can never run.

Preview vs Export

  • Preview — see it as a real page opens your page on its own, in the device's default browser, with nothing of the workshop around it. That is exactly how the world will see it.
  • Export — save the page as a file downloads the finished .html file. Double-click it anywhere and your page opens. Keep it, copy it, give it away.
  • Both are built from the same serializer, so the preview is the export, opened instead of saved — what you preview is exactly what you would get.

Your work is kept in this browser

Every change is autosaved into this browser's own storage (called localStorage) as you work. Close the tab, come back tomorrow, and your page is still here. The honest limits: it lives in this browser on this device only, and clearing the browser's site data would clear it too. Export is how you keep a copy forever. New Page wipes the sheet back to the starter page — it asks first, because it clears your work.

Learn more — the real references

  • MDN — HTML: the friendly encyclopedia of every HTML element.
  • web.dev — Learn HTML: a free course that starts at the very first tag.
  • web.dev — Learn CSS: the companion course for dressing pages up with style.
  • MDN — CSS: every style property, explained with examples.
  • The HTML Living Standard (WHATWG): the actual rulebook the browsers follow — heavy reading, and the real thing.
  • W3C Markup Validator: paste your exported page in and the official checker will read its code.
  • MDN — XML introduction: HTML's stricter cousin, the format behind a thousand data files.

One honest note for the grown-ups

The formatting buttons are powered by the browser's built-in document.execCommand — an old tool that the standards world has marked deprecated, but which every browser still ships and supports. The lesson page names that plainly and shows the interaction tests that were driven against this page before it shipped.
