THE WINDOWS LAYER - TRUMPET WINSOCK
====================================

If this machine also carries your own copy of Windows 3.1,
the period way onto the network from Windows was Trumpet
Winsock, and it is a two-piece bridge:

  1. The DOS packet driver loads first, as in the main
     workshop - Windows or no Windows, the card still
     belongs to the driver.
  2. WINPKT.COM (in this folder) loads after it. It is a
     shim: it presents the packet driver to Windows in
     the form Windows programs expect.
  3. Trumpet's TCPMAN then provides WINSOCK.DLL, the
     library every Windows network program calls.

Trumpet itself was shareware and is not in this pack. It
is preserved on archive.org (Trumpet Winsock v3.0c,
TWSK30C.ZIP) - which is where drivers and stacks of this
era were always found, by working techs, in the field.

One warning, from the man who ran it, in his words:

  "Trumpet winsock was a doozy great, but things got
   confused if you had winsock.dll in a couple of
   places."

Every stack shipped its own WINSOCK.DLL, and Windows
loads the first one it finds on the search path - not
the right one. Two copies in two places and half your
programs are talking to a stack that is not running.
The field cure was never a settings screen: find every
copy on the disk, and make there be one.
