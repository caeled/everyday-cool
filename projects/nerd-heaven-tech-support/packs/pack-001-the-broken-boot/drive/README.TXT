PACK 001 - THE BROKEN BOOT
==========================

This folder is the C: drive of a small front-desk machine.
Every morning the person at the desk turns it on and runs one command:

    AUTOEXEC

That sets up the machine and prints the morning report.
This morning, it doesn't. The report program "is gone" - except it isn't.

Your job, at the bench:
  1. Mount this drive (the DOS Workbench or the DOS Console).
  2. Run AUTOEXEC and watch what happens.
  3. Find the fault the bench way: read the error literally,
     prove where things are, follow the chain.
  4. Fix it so the workday starts clean.

The full lesson walks it:
  The DOS Workbench lesson pages, Nerd Heaven, Everyday Cool.

Everything on this drive is batch files and text - read any of it
with TYPE. Nothing here can harm anything. It is a drive that is
broken in exactly one place, on purpose.
