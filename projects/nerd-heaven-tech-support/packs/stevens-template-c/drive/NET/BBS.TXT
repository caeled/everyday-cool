THE PHONE BOOK - boards that still answer
==========================================

From the bench at Nerd Heaven, 26 November 2026. Every number below
was drawn from the Telnet BBS Guide (telnetbbsguide.com), which keeps
the master list and re-verifies it. Boards sleep, move, and retire
like they always did - if a number does not answer, check the Guide
for the new one. That was true of every list ever passed hand to hand.

HOW TO CALL (from this drive, on a machine with a network card -
DOSBox-X or real hardware; this web console fits no card):
  1. PNPPD 0x60        load the packet driver
  2. DHCP              ask the network for an address
  3. TELNET <number>   e.g. TELNET AGENCY.BBS.NZ
Ports other than 23 ride along: TELNET 20FORBEERS.COM 1337
