THE WINDOWS SLOT

On Steven's machine this folder holds an installed
Windows 3.x, and the WINSETUP folder beside it holds the
setup files it came from. Windows is Microsoft's, so the
template ships the folders empty, with his startup files
left standing in WINSETUP as the spec:

  WINSETUP\AUTOEXEC.BAT - read it closely: the first PATH
  entry is C:\MSBOB. His Windows machine had a Bob layer.
  The template makes no apology for this.

Install your own Windows 3.x from your own media into
these folders and the root AUTOEXEC.BAT ends, as his
does, with win.
