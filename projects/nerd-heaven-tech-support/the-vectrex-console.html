What this is

The Vectrex (GCE, 1982; later Milton Bradley) — the only home console that drew its pictures with a beam of light on its own built-in vector monitor. No pixels, no raster: lines, drawn the way an oscilloscope draws them. This page is that machine, whole — the JSVecX emulator, vendored beside the page, running entirely in your browser. It ships with no cartridges: your games stay yours, on your machine, and are read locally and never uploaded.

It is already playing

With an empty slot, a real Vectrex boots the game built into the machine itself — Mine Storm, its Asteroids. So does this one: the screen below is live the moment the page loads. Press A (button 1) to start a game.

The cartridge slot

  • Pick a cartridge — a .vec or .bin Vectrex cartridge image from your own library — or drag the file onto the screen.
  • The file is read by your browser, on your machine. Nothing is uploaded, ever.
  • Eject empties the slot and the machine goes back to Mine Storm, like pulling a cartridge out of the real slot.

The keys are read at the page level, so there is no focus trap: they work wherever you clicked last on this page. (They pause while you are typing in the Archive box below — typing is typing.) The stick is a digital stand-in: the real Vectrex stick is analog and self-centring, and this keyboard gives it full deflection or none. The lesson names that bend.

Glow and overlays — the two Vectrex things

  • Glow — a phosphor bloom the page lays over the tube. The emulator draws the same white-hot lines at every setting; the glow is this room's lighting, and the slider is yours.
  • Overlay — Vectrex games shipped with printed plastic overlays that clipped over the monochrome screen to give it colour zones. Ours are single-hue tints in their spirit — page furniture, exactly the trick the emulator author's own demo page uses — and the lines underneath never change.

Window size, fullscreen, pop out

Standard / Large / Extra large set the tube's size. Fullscreen fills the display; Pop out moves the live machine into a full-window overlay without restarting it — handy on a second screen or a TV. Esc or Pop back in returns it.

Sound

The machine's AY-3-8910 sound chip is emulated. Browsers keep sound locked until you touch a key or a button, so the first press wakes it. The Sound button under the screen turns it off and on.

What this machine cannot do

There are no save states. JSVecX has none to give — no state codes, no hand-off file, no Baton Box passenger for this console. A Vectrex game here is played the 1982 way: in one sitting, from the beginning. The lesson is plain about it.

Running this page as a lone file

This console is the one machine in the Emulator Box that runs from a double-clicked local file: the engine is plain scripts, the slot reads files locally, and nothing is fetched at runtime. Save the page with its jsvecx/ folder beside it and it works off the desktop, off a USB stick, anywhere.

The fine print

JSVecX is a JavaScript port by raz0red of VecX, written by Valavan Manohararajah, under the GPL v3 — vendored unmodified in jsvecx/ beside this page, license carried with it. The machine's own exec ROM rides inside the engine as upstream ships it; the lesson tells that story in the open, including why it is defensible here. No games are included with this console.

On a touch screen: this console is flown from the keyboard (arrows and letter keys) and has no touch controls — it needs a keyboard.

☄️ The game that's already in

Every Vectrex ever sold carries Mine Storm in its own ROM — steer the ship, shoot the mines, don't touch one. It was Steven's first Asteroids, on the first console he ever played. It needs no cartridge, no download, and no permission slip: it's part of the machine, and the lesson explains the paperwork that lets it ride here in the open.

📚 Or borrow from the public shelf

These cartridges live at the Internet Archive, in their house. Our slot can't reach across and take one — the Archive's file servers don't send the permission header a page needs — so a button opens the Archive's own player in a new tab, where the game runs there. We host no games here; this page only opens the door. (To play one in this machine, download the cartridge file from its Archive page and put it in the slot above — it's yours to keep.)
