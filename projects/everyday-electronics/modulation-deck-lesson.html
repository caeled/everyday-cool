Modulation Deck — the lesson

The bench is three traces: a message, a fast carrier bent into the message's shape, and the message pulled back out at the far end. Modulation is how a slow signal rides a fast wave — bend the carrier's size and you have AM, bend its spacing and you have FM. This page is the other half of the bench — the maths, the demodulators, the proof the recovery really works, and the one classic failure the bench lets you dial in on purpose — readable while you play, from the 📖 Lesson button in the game.

What this is

A voice, a song, a data stream — all of them are slow, wobbling signals, and none of them travel well on their own. An antenna sized for a 200 Hz tone would be hundreds of kilometres long. So radio cheats: it takes a fast, well-behaved wave — the carrier, at frequency fc — and lets the slow message (at fm) reshape it. The reshaped wave is what actually flies. At the receiver, a demodulator undoes the reshaping and hands you your message back. Everything on the bench happens sample by sample at fs = 48,000 Hz, with the defaults fm = 200 Hz and fc = 8,000 Hz — a carrier-to-message ratio of 40, and the deck enforces fc ≥ 20·fm whatever you do with the sliders, because a carrier that isn't much faster than its message isn't a carrier.

The message m̂(t) is always normalised — scaled so its peak is 1 — whether you pick the sine, the triangle, the square, or the two-tone pair. That one convention is what makes the modulation index μ and the deviation Δf mean the same thing for every shape.

The maths: AM

s(t) = (1 + μ·m̂(t)) · cos(2πfct) The carrier's amplitude becomes 1 + μ·m̂(t). μ is the modulation index: μ = 0 is a bare carrier saying nothing, μ = 1 swings the envelope exactly between 0 and twice the carrier. With the defaults (μ = 0.8, fm = 200 Hz) the sidebands sit at fc ± fm and the whole signal fits in 2·fm = 400 Hz of bandwidth.

Demodulating AM is beautifully cheap, which is why early radios were cheap: a diode and an RC pair. The diode charges a capacitor to each positive carrier peak; between peaks the capacitor bleeds down through the resistor, v *= exp(−Δt/RC) per sample. The bench simulates exactly that, per sample — no idealised envelope is ever drawn. The recovered message is (envelope − 1) / μ.

1/fc ≪ RC ≪ 1/fm The detector's one rule. RC must be long next to a carrier period (so it smooths the carrier away) and short next to a message period (so it can still follow the message). Proof settings: 1/fc = 0.125 ms ≪ RC = 1.00 ms ≪ 1/fm = 5.00 ms.

The maths: FM

s(t) = cos( φ(t) ),   φ += 2π ( fc + Δf·m̂(t) ) / fs   per sample The carrier's instantaneous frequency is fc + Δf·m̂(t): the message doesn't touch the size, it pushes the wave's spacing wider and narrower. Δf is the peak deviation and β = Δf / fm is the FM modulation index — with the defaults, β = 1000 / 200 = 5.00. The bench accumulates the phase one increment at a time, and the proofs measure the deviation back off those very increments — the same way the discriminator sees it.
B ≈ 2 ( Δf + fm )   — Carson's rule FM's bandwidth price tag. Defaults: 2 × (1000 + 200) = 2,400 Hz — six times AM's 400 Hz for the same message. That extra room is a large part of why FM sounds cleaner: the message lives in the frequency, where amplitude noise can't easily follow.

Demodulating FM: the bench mixes the signal down with cos and −sin at fc to get I and Q, low-passes them, and takes the angle of the resulting phasor sample by sample. Differentiating that angle gives the instantaneous frequency; subtract fc, divide by Δf, and the message falls out. That is a real discriminator, not a peek at the transmitter's notebook — the demodulator only ever sees s(t).

The proof

Every number below was measured by extracting the pure core out of the shipped game page and running its own runProofs() under Node against that exact code — the same core the bench draws with, no second implementation. Correlations are Pearson, DC-removed and gain-free, best lag within ±400 samples, with the first and last 2,000 samples skipped so filter warm-up can't flatter or sink the result. Settings: fs = 48,000 Hz, fm = 200 Hz, fc = 8,000 Hz, sine message, 0.2 s runs.

Where it bends — named honestly

Diagonal clipping is shown, not hidden. Push the detector RC slider far right (RC = 50 ms against a 5 ms message period) and the recovered trace stops following the envelope's falling edge: the capacitor cannot discharge fast enough, so the output saws diagonally across the message. Measured correlation falls from 0.9946 to 0.8376. Real AM radios suffer exactly this when the detector's RC is too large for the modulation — the bench treats it as a feature you dial in and watch, and the regime readout names it while it's happening.

Overmodulation is real distortion, not a warning label. Past μ = 1 the term (1 + μ·m̂) tries to go negative; a real carrier can't have negative size, so it flips phase instead, and the envelope the diode sees is the folded shape. Recovery degrades to 0.9715 — still recognisable, audibly and visibly wrong. The bench lets you go to μ = 1.6 because that's where the lesson is.

The other bends. The envelope detector charges instantly to a peak — a real diode and source resistance charge fast, not infinitely fast, so a hardware detector ripples a touch more than this one. The FM deviation proof (error 0.000%) is exact by construction: the deviation is measured off the same phase increments that set it, so it verifies the synthesis arithmetic, not a measurement through noise — the honest FM test is the discriminator correlation, 0.9993, which does go through the full receive chain. There is no noise, fading, or interference anywhere on this bench; a real channel adds all three, and adding them is a different exhibit. Correlations allow the best lag within ±400 samples, so they grade the recovered shape, not the demodulators' small, real delays.
