# Third-party notes — Flynn's Arcade

- All game pages are original works built for Steven Powell on 21 November 2026
  (see `COLLECTION.md`). No third-party code or assets are bundled.
- Typography: the pages load **IBM Plex Sans / IBM Plex Mono / Bungee** from
  Google Fonts at runtime when online. Nothing is copied into this project;
  offline, the pages fall back to system fonts.
- The bulletin board and hub link out to public reference sites (Wikipedia,
  Pagat, Bicycle Cards, CardGames.io, EverybodyWiki, and others). Those are
  ordinary hyperlinks; no content from them is reproduced beyond link text and
  short factual descriptions written for this project.
- The arcade banner photograph (`assets/arcade-banner.webp`) is an AI-generated
  image created for this project.
- Historical games referenced (Crossroads of the Elements, 1992, High Velocity
  Software; Infinity Complex, 1988, Steve Neal) are honoured with original
  reskins written for this project; no original code or assets are included.
