How this board grows

Every pin on this board lives in one list at the top of the page's code — the PINS list. That's deliberate, so adding a link never means regenerating the whole page.

  1. Find a link worth keeping — a game, a rule book, a wiki article.
  2. Pin it above, or just tell Muse the link and the game name.
  3. Muse adds one object to PINS: { title, url, cat, desc } — and republishes. Everything else stays exactly as it was.
  4. New categories work the same way: add a section name once, then keep pinning.

House rule from the arcade itself: links here were checked when pinned. If a site moves or dies, unpin it and pin its replacement — breakage is the audit.

Start anywhere: CardGames.io if you want a game in ten seconds, Pagat if you want the rules for a game nobody's written down since 1973, Bicycle if you want the house to settle an argument.
