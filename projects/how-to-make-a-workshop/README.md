# 🛠️ How to Make a Workshop

**The meta workshop: how an Everyday Cool workshop gets made — the method,
the plumbing, and the receipts — taught from the collection itself.**

Every workshop in this collection was made the same way: start with a
question a person actually has, build the smallest bench that lets them
ask–try–notice–understand, audit it like you don't trust it and print the
receipts, wire it honestly (counts from one source, provenance for every
file), and let a human decide whether it joins.

This room teaches that method and keeps the door open: the contribution
route is part of the lesson. An idea is enough to start — you do not have
to build anything to bring one.

## What's inside

- `index.html` — the workshop: the five moves, the three pieces of
  plumbing (AI-Delivery, The Baton Box, provenance and the gate), a
  copyable wiring checklist, and the "Bring one" contribution section.
- `how-to-make-a-workshop-lesson.html` — this workshop's own receipts:
  what the page claims, what was checked, and what bends.

## Carry it
