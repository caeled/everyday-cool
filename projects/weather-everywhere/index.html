THE ANTARCTICA QUESTION

How can it be summer
on a frozen continent?

Summer means a season, not a promise of warmth. Antarctica’s coast can approach freezing in summer; its high interior stays much colder. The ocean, elevation, latitude, and sunlight all matter.

ILLUSTRATIVE MODEL

What this little model can—and cannot—tell us

Density is a linear approximation near ordinary seawater: warmer water is less dense; saltier water is denser. Our circulation index combines an invented wind contribution and density contrast. The coast relaxes toward an invented heat-influence target over 30 model steps. Changing salinity affects that pathway, not rain directly.

The moisture index uses warm-water evaporation potential and wind direction. It is not rainfall in millimeters. This model omits Earth's rotation, real geography, ocean depth structure, clouds, storms, and many feedbacks. Steps have no real-world time unit. Never read this as an AMOC forecast or a prediction for a named place.

Build a cloud

The science behind the picture

We estimate dew point using the Magnus formula, then cloud base as about 125 meters for each degree Celsius between temperature and dew point. Unsaturated air cools about 9.8°C per kilometer; above cloud base we use a fixed 6°C per kilometer to illustrate latent heat release. The real saturated cooling rate varies.

This is a single parcel sketch. It doesn’t predict rain, cloud thickness, or the full weather behind the mountain. Cooling to saturation can form a cloud; having a cloud does not guarantee rainfall.
