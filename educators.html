Portable Workshops for Curious Minds

Everyday Cool is a free collection of hands-on workshops you can run from a downloaded folder. No student accounts, no logins, no tracking, no subscriptions — open a workshop and start learning.

WHY IT FITS

Built for real rooms

Nothing to sign up for. The collection asks for no accounts and collects no student data. Activities run locally in the browser; the front page works without JavaScript, and search and filters work locally when it is enabled.

It travels. Download the complete collection once, and the eight bundled workshops run offline from the folder — on a classroom set of laptops, a library machine, or a single shared computer. Individual workshop ZIPs are in the collection too.

It is honestly licensed. Hub code is MIT and original lessons are CC BY 4.0, so you may use and adapt the material for teaching with credit, and identify your changes. Everyday Cool is a growing educational collection, not an accredited school or certification authority — treat it as a supplement you choose and pace yourself.

RUNNING A SESSION

Ask, try, notice, understand

Every workshop follows the same rhythm printed on the front page: Ask → Try → Notice → Understand. Each card’s “Start here” activity is a ready-made session opener, and the learning paths suggest an order when you want a sequence: beginner workshops for first contact, intermediate benches for guided practice, advanced workshops for independent work.

Useful discussion prompts after any activity:

  • What did you change, and what happened?
  • What surprised you?
  • Where is this system hiding in everyday life?
  • What would you test next, and what do you predict?

Examples inside the workshops are fictional by design — Internet Detective’s case files, for instance, teach verification habits without touching anyone’s real accounts.

PRACTICAL NOTES

Before the bell rings

  • Download ahead of time. Core activities are bundled for offline use; videos, external reading destinations, and live weather still need internet.
  • Try it on your network first. A quick run-through on the machines students will use beats discovering a blocked feature mid-lesson.
  • A few features want a secure context. Some cryptography features require HTTPS or localhost. The collection’s Serve.cmd helper serves the folder locally using an existing Python 3 installation.
  • Accessibility is a standing requirement. Workshops aim for readable navigation, keyboard access, labels, and contrast, with no compulsory motion or autoplay. If a student hits a barrier, a correction issue is genuinely welcome — accessibility improvements are first-class contributions.
